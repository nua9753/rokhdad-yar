# رخدادیار

افزونهٔ وردپرس برای ساخت عنوان، چکیده، نامک، دسته و برچسب و تصویر شاخص با هوش مصنوعی، به‌همراه جعبه ابزار (پین در دسته‌بندی)، محافظ نامک، تاریخچه و گزارش مصرف.

## نصب
آخرین `rokhdadyar.zip` را از [Releases](https://github.com/nua9753/rokhdad-yar/releases/latest) بگیرید و در «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب کنید. از آن به بعد به‌روزرسانی‌ها مثل افزونه‌های مخزن وردپرس در پیشخوان می‌آیند (با امکان به‌روزرسانی خودکار).

## انتشار نسخهٔ تازه
1. شمارهٔ نسخه را در `rokhdadyar.php` (`Version` و `ROKHDADYAR_VER`) و `Stable tag` در `readme.txt` بالا ببرید و تغییرات را زیر `== Changelog ==` در `readme.txt` بنویسید.
2. کامیت و پوش کنید، بعد تگ بزنید: `git tag v2.14.1 && git push origin v2.14.1`
3. گیت‌هاب اکشن بستهٔ `rokhdadyar.zip` را می‌سازد و Release را منتشر می‌کند؛ سایت‌ها حداکثر ظرف ۶ ساعت (یا با «بررسی به‌روزرسانی» در ردیف افزونه، فوراً) نسخهٔ تازه را می‌بینند.
